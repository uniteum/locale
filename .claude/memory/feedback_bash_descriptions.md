Don't use hedging language like "2>/dev/null" redirects or "Check if X exists" style descriptions for bash commands. Just describe what the command does plainly.

**Why:** User finds overly cautious command patterns annoying.
**How to apply:** Write bash commands and descriptions directly without defensive framing.
